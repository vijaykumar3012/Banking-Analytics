# Banking-Analytics

🚀 **Banking Analytics SQL Project | Turning Banking Data into Insights**

I’m excited to share my **Banking Analytics SQL Project**, where I worked with a relational banking database to analyze customers, accounts, transactions, loans, branches, and customer segments.

### 🔍 Project Highlights

📌 **Database:** `banking_analytics_db`
📌 **Tool:** MySQL / MySQL Workbench
📌 **Key Tables:** Customers, Accounts, Transactions, Loans, Branches

### 💡 SQL Concepts I Practiced

✅ Database and table creation
✅ Primary & foreign keys
✅ Joins for combining customer and loan information
✅ `GROUP BY` & aggregate functions
✅ `COUNT()` and `SUM()` for banking metrics
✅ `CASE WHEN` for conditional analysis
✅ `COUNT(DISTINCT)` for customer segmentation
✅ Window functions such as `LAG()`
✅ Transaction analysis using previous transaction amounts
✅ Loan-status and loan-amount analysis

### 📊 Example Insights

🔹 Calculated total deposits using conditional aggregation
🔹 Analyzed the number and total value of loans by loan status
🔹 Connected customers with their loan information
🔹 Counted customers across different customer segments
🔹 Compared each transaction amount with the previous transaction using `LAG()`

This project helped me strengthen my understanding of **SQL for real-world financial data analysis** and how raw banking data can be transformed into meaningful business insights.

🎯 **Next Goal:** Continue building more end-to-end Data Analytics projects using **SQL, Python, Excel, Power BI, and Databricks**.
